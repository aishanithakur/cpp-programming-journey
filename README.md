# C++ Beginner Programs

A collection of beginner-friendly C++ programs that I'm writing and practising as I strengthen my programming fundamentals.

## 📚 What I'm Learning

- C++ fundamentals and conditional statements
- Loops and numerical problem-solving

- Digit manipulation and mathematical operations
- Nested loops and pattern printing
- Breaking problems into smaller, reusable functions
